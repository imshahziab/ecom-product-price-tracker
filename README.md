# E-Commerce Product Price Tracker & Automated Web Scraper

A lightweight, automated Python data extraction utility built using **BeautifulSoup** and **Requests** to scrape product catalogs, track live price movements, and export clean, structured datasets into CSV formats.

---

## 📌 Project Overview
E-commerce intelligence relies on accurate real-time market data. This automated script parses web HTML structures, handles pagination, cleans currency strings, and formats unstructured web data into structured tables ready for pipeline ingestion.

### Key Features:
- **Automated Data Scraping:** Extracts titles, live pricing, and inventory stock status.
- **Data Transformation:** Cleans special character encodings and structures datatypes.
- **CSV Ingestion Pipeline:** Exports data directly into timestamped CSV reports.

---

## 🛠️ Tech Stack

- **Libraries:** BeautifulSoup4, Requests, CSV, Datetime
